v0.7.2 저장 메뉴 모드 구분 보완

1. 게임 중: 스토리/미션/커스텀 중 현재 플레이 중인 모드만 표시. 다른 모드 선택 불가.
2. 타이틀: 스토리 / 미션 중 명시적 선택 후 저장 관리 진입. 커스텀 테스트 저장도 별도 접근.
3. 타이틀에서 슬롯 저장은 선택 모드의 기존 자동 저장을 복사하는 동작임을 명확하게 표시. 자동 저장 없으면 저장 버튼 비활성화.
4. 타이틀 모드 변경 버튼은 다시 모드 선택 화면으로 이동.
5. 슬롯 이름/확인/저장 알림에 모드 명시.
6. 저장 키, 저장 포맷, 모드별 슬롯 3개, 자동 저장, 파일 백업 유지.
7. 브라우저 업데이트를 위해 서비스 워커 및 게임 스크립트 캐시 식별자 갱신.
