cnation TACTICS v0.7.2 — 기기 로컬 저장 개선

기준: v0.7.1 속성 파티클 강화 통합본

1. 기존 자동 저장 유지: 스토리/미션/커스텀별 localStorage에 진행 상황 저장. 마지막 저장 시각 기록 추가.
2. 수동 저장 슬롯: 모드별 3개, IndexedDB 저장 우선. IndexedDB 차단 시 localStorage 대체 저장 및 표시.
3. 슬롯 저장/불러오기/삭제/개별 파일 내보내기. 덮어쓰기·불러오기·삭제 시 확인 화면.
4. 타이틀 및 전투 메뉴에서 저장 관리 진입. 게임 설정 화면에도 바로가기.
5. 자동 저장 불러오기: 현재 메모리가 아니라 디스크에 마지막으로 기록된 자동 저장을 사용.
6. JSON 백업: 스토리/미션/커스텀 모드 지원. v0.7.2 메타데이터 포함. 기존 스토리 JSON 형식도 가져오기 지원.
7. 저장 주의사항: iPhone Safari 일반 탭의 ITP 7일 조건부 정리, 홈 화면 PWA 예외, PWA 삭제/저장 공간 정리 위험, 파일 백업 권장.
8. 스토리/미션/커스텀 자동 저장 키와 기존 게임 세이브 포맷(version:1)은 유지.
9. 게임/서비스워커 캐시 버전 v0.7.2로 갱신.

검증:
- node --check game.js 구문 검사
- Node VM 저장 모듈 단위 검사 (대체 저장소, 스냅샷, 모드 유효성, 백업, 삭제, 복구, iOS 경고)
- ZIP 무결성 검사
- 실제 iPhone Safari/PWA 브라우저 실행 검증은 별도 필요
