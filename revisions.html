ver.1.1.0 2026-10-16

추가

  • 실제 배경음악 적용. 전투 외 모든 화면(타이틀·지도·야영지·승리/패배·엔딩 등)은 1번 곡 「Title Theme」.
  • 모든 전투(보스전 포함)는 4~7번 곡 중 하나를 무작위로 재생하고, 직전 전투와 같은 곡은 나오지 않습니다. 같은 전투를 이어하기로 다시 열면 같은 곡이 이어집니다.
  • 곡이 끝나면 앞뒤 무음 구간을 잘라내고 짧게 겹쳐 자연스럽게 처음부터 다시 연주합니다.
  • 1번 곡은 게임 첫 실행 시, 전투 곡은 처음 필요할 때 불러와 메모리에 보관하고 재사용합니다. 불러오는 동안 「게임 데이터를 불러오는 중입니다.」 안내를 표시합니다.
  • 설정에 「배경음악 볼륨」 추가 (끄기·25%·50%·75%·100%). 효과음이 잘 들리도록 기본값은 50%입니다.
  • 한 번 재생한 음악 파일은 오프라인에서도 재생되도록 저장됩니다.

참고

  • 음악 파일(WebM/Opus)을 재생하지 못하는 오래된 브라우저(iOS 17.4 이전 등)에서는 기존처럼 게임이 직접 만든 음악이 나옵니다.

ver.1.0.1 2026-10-16

수정

  • 상 난이도 6장(특히 보스전 「아르카 감시자」)에서 일부 지도(약 1.3%)가 적 배치 공간 부족으로 생성되지 않아 전투가 시작되지 않던 문제 수정. 공간이 부족할 때만 적 사이 간격을 한 칸씩 줄여 배치하며, 기존에 정상 생성되던 지도는 그대로입니다.
  • 오프라인 캐시(서비스 워커)가 게임 외의 페이지를 게임 화면 캐시로 덮어쓸 수 있던 문제 수정.

변경

  • 타이틀 화면 하단에 ver.1.0.1 (rev. history) 표시. rev. history를 누르면 이 페이지가 열립니다.
  • 파일 구조 분리: 3D 라이브러리(three.js r170)를 vendor/three-r170.js로 분리하고 game.js에는 게임 코드만 남김. 게임 로직 변경 없음.
  • 개발용 문서 정리: QA 기록 24개, CHANGELOG.txt, DEVELOPMENT_CONTEXT.md, README.txt, run.bat 삭제. 요약은 아래 「1.0 이전 개발 기록」으로 옮김.
