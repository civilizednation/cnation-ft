cnation TACTICS v0.6.40 — 수정 파일 패키지

v0.6.39에 외부 배경음악 5곡 연결과 음악 볼륨 50%를 반영했습니다.

1. GitHub 업로드
기존 index.html / game.js / sw.js를 이번 파일로 덮어쓰세요.
기존 manifest.webmanifest / icon.png는 그대로 사용합니다.
압축에는 게임 수정 파일 3개와 문서 3개가 포함됩니다. 음악은 중복 포함하지 않았습니다.

2. 음악 위치 — 파일명을 바꾸지 마세요
index.html과 같은 루트 폴더 아래 bgm 폴더를 만들고,
첨부했던 cnation_webm_5files.zip의 파일 5개를 그 안에 직접 넣으세요.

bgm/01. Title Theme_64k.webm
bgm/04. Blades of the Young_64k.webm
bgm/05. March of the Broken Banner_64k.webm
bgm/06. When Kingdoms Fall_64k.webm
bgm/07. Awakened Colossus_64k.webm

대소문자·공백·숫자를 포함한 실제 파일명과 일치해야 합니다.
JS는 공백을 포함한 URL을 자동으로 인코딩하며, GitHub Pages 하위 경로에서도 연결됩니다.

3. 음악 동작
01은 게임 실행 즉시 로딩합니다. 전투 외 모든 화면에서 같은 곡을 계속 반복합니다.
전투 시작 시 01을 멈추고 위치를 기억하며, 전투가 끝나면 그 위치부터 이어집니다.
전투는 04/05/06/07 중 직전과 다른 곡을 무작위로 선택해 한 곡만 반복합니다.
전투곡은 전투 전에 선택된 곡만 로딩합니다. 처음부터 4곡을 모두 로딩하지 않습니다.
이미 불러온 곡은 페이지 메모리에서 바로 재사용하며, 동시에 요청해도 한 번만 로딩합니다.
페이지를 닫거나 새로고침하면 메모리 캐시는 초기화합니다. 저장된 전투는 같은 곡으로 이어합니다.
재도전은 새 전투로 보고 직전과 다른 곡을 선택합니다.
모든 음악의 재생 볼륨은 50%이고, 효과음은 기존 음량입니다.
모바일 브라우저의 자동 재생 정책에 따라 실제 재생은 첫 화면 터치 이후 시작됩니다.

4. 저장·오프라인
기존 진행 기록을 유지합니다. 업데이트 확인은 타이틀/설정의 v0.6.40을 보세요.
코드·아이콘 등의 PWA 캐시는 갱신합니다. 음악 5곡은 선캐시하지 않습니다.
현재 페이지에서 이미 로딩한 음악은 오프라인에서도 재사용되지만 아직 로딩하지 않은 곡은 인터넷이 필요합니다.
저장 데이터 삭제 전에 설정에서 저장 파일을 내보내세요.
로컬 실행은 기존 run.bat 또는 python3 -m http.server 8080으로 서버를 실행하세요.

5. 확인한 동작
실제 첨부 음악으로 첫 곡 즉시 로딩, 전투곡 지연 로딩, 10회 랜덤/연속 중복 없음,
01 위치 복귀, 5곡 다운로드 중복 없음, 모든 곡 50% 음량, 곡 끝 반복, 재도전,
음소거·백그라운드 복귀 및 저장 유효성·브라우저 예외 없음 등을 Chromium에서 확인했습니다.
실제 iPhone Safari와 스피커 청취는 별도 확인이 필요합니다.
이전 v0.6.38~39의 방향·투사체·상태 연출·공격/방어 백과사전·투명 방향 버튼 수정은 유지했습니다.
