cnation TACTICS v0.6.30 — 전체 게임 / Windows 로컬 실행 패키지

이 패키지는 v0.6.9에 v0.6.10~v0.6.30의 누적 수정 내용을 반영한 완전한 배포본입니다.
Three.js도 game.js에 포함되어 있습니다. 실행 시 npm 설치, 빌드, CDN 다운로드가 필요하지 않습니다.
BGM은 아직 포함하지 않았으며 효과음은 브라우저에서 직접 생성합니다.

1. 노트북에서 실행하기 (Windows 10/11)
- ZIP을 먼저 전체 압축 해제하세요. 압축파일 안에서 run.bat를 바로 실행하지 마세요.
- Python 3.7 이상이 필요합니다. 없으면 https://www.python.org/downloads/windows/ 에서 설치하세요.
  설치 화면의 “Add python.exe to PATH”를 선택한 후 run.bat를 다시 실행하세요.
- run.bat를 더블 클릭하면 서버가 실행되고 기본 브라우저로 http://localhost:8080/ 이 열립니다.
- 실행 창을 열어둔 채 Chrome 또는 Edge에서 플레이하세요.
- 브라우저가 자동으로 열리지 않으면 위 주소를 직접 입력하세요.
- 종료: 실행 창을 닫거나 Ctrl+C를 누르세요.
- 8080 포트 사용 중 오류: 다른 로컬 서버를 종료하거나 run.bat의 GAME_PORT=8080을 8081로 변경하세요.
- run.bat가 열리지 않으면 우클릭 → 편집으로 내용을 확인하고 명령 프롬프트에서 실행할 수 있습니다.

2. 수동 실행 / 다른 운영체제
이 폴더에서 터미널을 열고 아래 명령을 실행하세요.
Windows: py -3 -m http.server 8080 --bind 127.0.0.1
macOS/Linux: python3 -m http.server 8080 --bind 127.0.0.1
접속: http://localhost:8080/
index.html 더블 클릭 실행은 PWA·오프라인 캐시가 제한되고 저장 동작도 브라우저별 차이가 있어 로컬 서버를 권장합니다.

3. GitHub Pages / Vercel
아래 5개 파일을 같은 폴더에 업로드하면 됩니다.
index.html / game.js / sw.js / manifest.webmanifest / icon.png
예전 파일은 덮어쓰세요. 이전 사이트를 v0.6.30으로 갱신할 때는 변경된 index.html / game.js / sw.js 3개만 업로드하면 됩니다.
run.bat와 문서 3개는 배포에 필요하지 않습니다.
타이틀 또는 설정에 v0.6.30이 표시되는지 확인하세요.
업데이트가 늦으면 인터넷 연결 상태에서 페이지를 다시 열거나 새로 고침하세요.
브라우저 저장 데이터를 삭제하기 전에는 반드시 설정에서 저장 파일을 내보내세요.

4. 저장과 오프라인
저장은 현재 브라우저·접속 주소별 LocalStorage에 보관됩니다.
GitHub에서의 진행 기록은 localhost로 자동 공유되지 않습니다.
기존 사이트 설정 → 저장 파일 내보내기 → 로컬 게임 설정 → 불러오기로 옮길 수 있습니다.
브라우저 또는 포트가 바뀌면 별도의 저장 공간을 사용합니다.
Service Worker는 localhost/HTTPS에서 작동하며 첫 실행 시 5개 게임 파일을 캐시합니다.
로컬 서버 실행은 인터넷 없이 가능하지만, 새 페이지를 열 때는 run.bat를 켜두는 것이 가장 확실합니다.

v0.6.21: 대사창의 ‘말하는 사람’ 문구를 제거하고 화자 이름만 굵게 표시.
v0.6.22: 장비 보관함을 전체 목록으로 열고 장착·해제 후에도 사용 중인 필터를 유지.

v0.6.28: 완료한 본편 전투에서 다음 본편으로 향하는 밝고 굵은 이동 화살표, 해금된 추가 전투로 향하는 가는 이동 화살표를 지도 길 위에 표시.
v0.6.29: 추가 전투 설명을 지도 바깥쪽 여백으로 옮기고 전투 종류 글자를 강조. 다음 본편 전투 시작 시 건너뛴 추가 전투를 닫되, 완료한 추가 전투의 재도전은 유지.
v0.6.30: 늪이나 이동 불가능한 칸에 전장 아이템이 생기지 않도록 이동·점프 경로를 검사. 이전 저장 기록의 잘못 놓인 아이템도 안전한 칸으로 이동.
기존 커스텀 모드, 53개 무작위 전장, 적 분산, 이동 중 아이템 획득, HP 비교 등 유지.
CHANGELOG.txt에 전체 수정 이력, DEVELOPMENT_CONTEXT.md에 개발 인수인계 정보가 있습니다.

6. 검증 범위
Chromium에서 게임 실행, 3D 지도·대화, 전투 시작 배치, 제자리 마법 후 이동, 상점 구매·장착과 모델 갱신을 확인했습니다.
v0.6.15의 백과사전 탭은 Chromium 500/375/320px 너비에서 마지막 항목까지 표시·선택을 확인했습니다. v0.6.16에서는 아군 근접 공격 후 적 HP 감소와 적 턴 근접 공격 후 아군 HP 감소를 확인했고 브라우저 오류가 없었습니다.
v0.6.14에서 53개 임무 × 10개 시드 × 3개 난이도 = 1,590개 새 맵의 적 배치·획득물 위치와 375×667 화면을 검사했습니다. v0.6.13에서는 1,590개 맵의 생성, 53개 임무 대화, 15개 선택 임무 이름, 9개 보스 프로필도 검사했습니다.
손상된 저장 분기와 서비스 워커 오프라인 재실행을 확인했습니다. 기존 백과사전·정화·로컬 서버 확인 내용은 v0.6.12 검증에 포함됩니다.
v0.6.17에서는 Chromium에서 백과사전 지형 선택과 물 타일 미리보기, 2장 강 전장의 실제 수면 표시를 확인했습니다. 브라우저 오류가 없었습니다.
v0.6.18에서는 Chromium 10×10·14×14 전장에서 추가 줌인과 초기 진영 배치, 콘솔 오류 없음을 확인했습니다.
v0.6.19에서는 Chromium 전장에서 케이스형 획득물 표시와 탭하여 획득하는 동작, 콘솔 오류 없음을 확인했습니다.
v0.6.20에서는 Chromium 서막 대화에서 화자가 바뀌어도 두 인물의 좌우 위치가 유지되고 이름표·대사창 화자가 함께 바뀌는 것을 확인했습니다.
v0.6.21에서는 Chromium 대화창에서 화자 이름만 표시되는 것을 확인했습니다.
v0.6.22에서는 Chromium 장비 보관함의 전체 필터와 장착 후 목록 상태를 확인했습니다.
v0.6.23에서는 Chromium 서막 지도에서 본편·추가 경로와 안내 표시, 콘솔 오류 없음을 확인했습니다.
v0.6.24에서는 Chromium 서막 지도에서 길·장소 모형·핀 표시와 콘솔 오류 없음을 확인했습니다. 53개 임무의 장소 모형 데이터와 경로 좌표도 검사했습니다.
v0.6.25에서는 Chromium 서막 지도를 320·375·595px 너비에서 확인하고, 지점 이름 배경이 투명한지와 다음 본편·잠긴 표식의 색 및 브라우저 오류 없음을 검사했습니다. 완료·추가 전투 색은 코드의 상태별 스타일을 확인했습니다.
v0.6.26에서는 Chromium 서막 지도에서 320·375·500px 너비의 다섯 설명이 다른 원형 표식이나 설명과 겹치지 않고 지도 밖으로 잘리지 않는지 확인했습니다.
v0.6.27에서는 동일 전장 시드로 첫 도전과 완료 후 재도전을 생성해 아이템 2개/0개를 확인하고, 이전 버전의 저장된 재도전 아이템도 0개로 정리되는 것을 검사했습니다.
v0.6.28에서는 서막 전투 1 완료 기록을 실제 저장 기록에 쓰지 않는 임시 미리보기로 열어 두 화살표의 방향과 375px 화면, 브라우저 오류 없음을 확인했습니다.
v0.6.29에서는 서막 전투 2 시작·완료 후 첫 추가 전투의 잠금, 완료한 추가 전투의 재도전 가능 상태, 서막·1장의 375px 설명 위치와 브라우저 오류 없음을 확인했습니다.
v0.6.30에서는 53개 임무 × 30개 시드 = 1,590개 전장의 아이템 2,392개가 안전한 칸에 있고 늪·물 위에 없는지 확인했습니다. 228개 아이템은 실제 이동 계산으로 여러 턴에 걸쳐 도달 가능한지 따로 검사했습니다. 저장된 전투·재시도 기록의 늪 아이템 재배치와 Chromium 실행·오류 없음도 확인했습니다.
Windows에서의 run.bat 더블 클릭과 실제 iPhone Safari는 이번 작업 환경에서 직접 시험하지 않았습니다.
