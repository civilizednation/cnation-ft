cnation TACTICS v0.7.15 · 전체 게임 소스
====================================

실행
- ZIP을 풀고 index.html, game.js, sw.js를 같은 폴더에 둡니다.
- 웹 서버에서 실행 권장: python3 -m http.server 8080
- 접속: http://localhost:8080/
- GitHub Pages 등 정적 웹 호스팅 가능.
- 게임 모델과 사운드는 코드에서 생성하며 외부 빌드/에셋 불필요.
- iOS Safari에서 홈 화면에 추가해 플레이 가능.

v0.7.12까지의 주요 변경
1. 아군 성장: 최초 승리 XP 70 + 전투 레벨×14, 광역 XP 행동당 최대 90,
   자신보다 레벨이 낮은 적 상대 XP 감소.
2. 재도전: 최초 보상의 10% EXP(전투 행동 포함), 전장 아이템 없음,
   승리 골드 없음. 재도전 전 확인/취소 안내 창 표시.
3. 재도전 승리 물약 1개 보너스와 HP 회복 유지.
4. HP 회복: 일반 승리 시 잃은 HP의 50%, 손실이 최대 HP의 10% 이하라면
   100% 회복, 챕터 마지막 정규전 승리 시 기존대로 전원 100% 회복.
5. 몬스터: 3~4장 +5%, 5~6장 +10%, 7~8장 +15%, 최종장 +20%의
   추가 HP·DEF·RES. 5~6장 +5%, 7~8장 +10%, 최종장 +12% 공격력.
6. 적 AI: 중 난이도에서 아군 4~6명일 때 선두 4~6명,
   후방 접근은 전투 4턴부터 최대 이동력까지 가속.
7. 선택 전투 최초 승리 골드 +25%, 보스 최초 승리 골드 +35%.
8. 전투 준비에서 챕터 수준 장비 장착 개수 안내.
9. v0.7.11 리아 마법 조정 및 기존 전투/백과사전 기능 유지.

저장 데이터
- 기존 저장 키/스키마 유지. 진행 중인 전투의 적 능력치는 그대로,
  다음 신규 전투부터 새로운 챕터별 몬스터 강화 적용.
- 기존 장비는 유지. Lv.41~50 영웅은 Lv.40으로 조정되며, 그 외 레벨은 유지.

v0.7.14: NORMAL 기준 챕터별 몬스터 강화, STORY·TACTICAL 능력치/피해 상한 재조정, 중·후방 적 접근 AI 강화. 전투 결과 화면과 여정 메뉴의 밸런스 기록(최근 30전)에서 자동 회복 전 평균 HP, 위험/전투불능 캐릭터, 물약, 적 공격, 장비 수준을 확인할 수 있습니다. 목표 잔여 HP는 플레이테스트 전 가설이며 보장 수치가 아닙니다.


v0.7.15 — 아군 성장 및 신규 동료 합류 조정
- 아군 최대 레벨 50 → 40. 몬스터 레벨/능력치/난이도는 기존 설정 유지.
- 다음 레벨 요구 EXP: 현재 Lv.1~25는 기존 80+18×Lv, Lv.26~30은 15% 증가, Lv.31~39는 30% 증가(소수점 올림). Lv.40 MAX.
- 신규 동료는 합류 당시 이미 합류한 아군의 평균 레벨(반올림)을 기준으로 생성하되, 해당 챕터 최소 레벨(1+챕터×3)은 보장. 전직·장비는 기존 수동 관리 유지.
- 구버전 저장의 Lv.41~50 캐릭터는 불러올 때 Lv.40으로 조정, 경험치 0으로 초기화. 기존 장비·전직·골드·스토리 진행은 유지. 진행 중 전투의 유닛 수치는 전투 종료 후 신규 전투부터 재계산.
- 커스텀 모드 테스트 레벨 선택 상한도 40. 미션/커스텀 모드의 자동 파티 레벨 설정은 그대로 유지.
