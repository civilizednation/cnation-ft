cnation TACTICS v0.7.10 · 전체 게임 소스
====================================

실행
- ZIP을 풀고 index.html, game.js, sw.js를 같은 폴더에 둡니다.
- 웹 서버에서 실행하는 것을 권장합니다. 예: python3 -m http.server 8080
- 접속: http://localhost:8080/
- GitHub Pages 등 정적 웹 호스팅에도 배포할 수 있습니다.
- 게임 모델/사운드는 코드에서 생성하며 별도 에셋이나 npm 빌드가 필요하지 않습니다.
- iOS Safari에서 웹 페이지를 연 뒤 홈 화면에 추가하여 플레이할 수 있습니다.

v0.7.10 주요 변경
1. 백과사전 몬스터 능력치가 실제 전투와 같은 계산식을 사용합니다.
   챕터/전투/난이도/일반·정예를 선택하며 전투 중에는 해당 적의 실제 수치를 우선 표시합니다.
2. 공격 예고창을 몬스터당 한 줄로 줄이고 피해·속성/방향 보너스·HP 변화만 표시합니다.
3. 일반/정예/보스 HP를 기존보다 약 30% 추가 강화합니다.
   DEF/RES는 일반 +10%, 정예·보스 +15% 강화합니다.
4. 아군 4~6명일 때 적 선두 접근 인원을 늘리고 후열 합류 속도를 소폭 높입니다.

저장 데이터
- 기존 v0.7.9 및 이전 버전 저장 데이터 구조와 호환되도록 설계했습니다.
- 기존 진행 중 전투의 몬스터 능력치는 저장된 값을 유지합니다.
- 새 전투부터 새로운 몬스터 능력치가 적용됩니다.
