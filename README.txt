cnation TACTICS v0.6.14 — 전체 게임 / Windows 로컬 실행 패키지

이 패키지는 v0.6.9에 v0.6.10~v0.6.14의 누적 수정 내용을 반영한 완전한 배포본입니다.
Three.js도 game.js에 포함되어 있습니다. 실행 시 npm 설치, 빌드, CDN 다운로드가 필요하지 않습니다.
BGM은 아직 포함하지 않았으며 효과음은 브라우저에서 직접 생성합니다.

1. 노트북에서 실행하기 (Windows 10/11)
- ZIP을 먼저 전체 압축 해제하세요. 압축파일 안에서 run.bat를 바로 실행하지 마세요.
- Python 3.7 이상이 필요합니다. 없으면 https://www.python.org/downloads/windows/ 에서 설치하세요.
  설치 화면의 “Add python.exe to PATH”를 선택한 후 run.bat를 다시 실행하세요.
- run.bat를 더블 클릭하면 서버가 실행되고 기본 브라우저로 http://localhost:8080/ 이 열립니다.
- 실행 창을 열어둔 채 Chrome 또는 Edge에서 플레이하세요.
- 브라우저가 자동으로 열리지 않으면 위 주소를 직접 입력하세요.
- 종료: 실행 창을 닫거나 Ctrl+C를 누르세요.
- 8080 포트 사용 중 오류: 다른 로컬 서버를 종료하거나 run.bat의 GAME_PORT=8080을 8081로 변경하세요.
- run.bat가 열리지 않으면 우클릭 → 편집으로 내용을 확인하고 명령 프롬프트에서 실행할 수 있습니다.

2. 수동 실행 / 다른 운영체제
이 폴더에서 터미널을 열고 아래 명령을 실행하세요.
Windows: py -3 -m http.server 8080 --bind 127.0.0.1
macOS/Linux: python3 -m http.server 8080 --bind 127.0.0.1
접속: http://localhost:8080/
index.html 더블 클릭 실행은 PWA·오프라인 캐시가 제한되고 저장 동작도 브라우저별 차이가 있어 로컬 서버를 권장합니다.

3. GitHub Pages / Vercel
아래 5개 파일을 같은 폴더에 업로드하면 됩니다.
index.html / game.js / sw.js / manifest.webmanifest / icon.png
예전 파일은 덮어쓰세요. v0.6.13 사이트를 v0.6.14로 갱신할 때는 변경된 index.html / game.js / sw.js 3개만 업로드하면 됩니다.
run.bat와 문서 3개는 배포에 필요하지 않습니다.
타이틀 또는 설정에 v0.6.14가 표시되는지 확인하세요.
업데이트가 늦으면 인터넷 연결 상태에서 페이지를 다시 열거나 새로 고침하세요.
브라우저 저장 데이터를 삭제하기 전에는 반드시 설정에서 저장 파일을 내보내세요.

4. 저장과 오프라인
저장은 현재 브라우저·접속 주소별 LocalStorage에 보관됩니다.
GitHub에서의 진행 기록은 localhost로 자동 공유되지 않습니다.
기존 사이트 설정 → 저장 파일 내보내기 → 로컬 게임 설정 → 불러오기로 옮길 수 있습니다.
브라우저 또는 포트가 바뀌면 별도의 저장 공간을 사용합니다.
Service Worker는 localhost/HTTPS에서 작동하며 첫 실행 시 5개 게임 파일을 캐시합니다.
로컬 서버 실행은 인터넷 없이 가능하지만, 새 페이지를 열 때는 run.bat를 켜두는 것이 가장 확실합니다.

v0.6.11: 화염 낙하·폭발, 낙뢰 및 속성별 그래픽·합성 효과음, 충분한 연출 시간.
v0.6.12: 30개 스킬 설명 및 백과사전 전체 상세화.
v0.6.13: 임무별 대화·선택 임무 정체성·보스 고유 패턴, 손상된 저장 원본 보호, 영웅 6명과 몬스터 10종의 3D 외형 강화.
v0.6.14: 제자리 공격·마법 후 이동, 아군 하단·적군 상단 시작, 근접 타격 연출, 챕터별 입체 지도와 인물 대화, 12종 3D 장비 수집·상점·시각적 장착.
기존 커스텀 모드, 53개 무작위 전장, 적 분산, 이동 중 아이템 획득, HP 비교 등 유지.
CHANGELOG.txt에 전체 수정 이력, DEVELOPMENT_CONTEXT.md에 개발 인수인계 정보가 있습니다.

6. 검증 범위
Chromium에서 게임 실행, 3D 지도·대화, 전투 시작 배치, 제자리 마법 후 이동, 상점 구매·장착과 모델 갱신을 확인했습니다.
v0.6.14에서 53개 임무 × 10개 시드 × 3개 난이도 = 1,590개 새 맵의 적 배치·획득물 위치와 375×667 화면을 검사했습니다. v0.6.13에서는 1,590개 맵의 생성, 53개 임무 대화, 15개 선택 임무 이름, 9개 보스 프로필도 검사했습니다.
손상된 저장 분기와 서비스 워커 오프라인 재실행을 확인했습니다. 기존 백과사전·정화·로컬 서버 확인 내용은 v0.6.12 검증에 포함됩니다.
Windows에서의 run.bat 더블 클릭과 실제 iPhone Safari는 이번 작업 환경에서 직접 시험하지 않았습니다.
